#  Movie Recommended System

##  Project Overview

The **Movie Recommended System** is a machine learning project designed to recommend movies based on movie preferences and similarities. It helps users discover movies they may enjoy by analyzing movie-related information and applying recommendation techniques.
This project demonstrates the practical application of Python, data preprocessing, machine learning, and recommendation systems.

##  Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook
